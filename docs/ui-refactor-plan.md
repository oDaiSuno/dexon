# 聊天内页 UI 重设计计划 · 方向 B「无界文档 · 安静纸感」

> 状态：**待批准**。批准前不动任何代码。
> 决策记录：范围 = 消息组件 + 欢迎页（composer 仅配色适配）；视觉方向 = B（预览：`.artifacts/ui-redesign/candidates.html`）；动效 = transitions.dev 体系，深度 = 关键时刻（约 8 处）。

---

## 1. 范围

**在范围内**

- 消息渲染组件：用户气泡、助手正文、流式状态、思考块、工具调用块、diff 视图、过程折叠组、compaction/extension 面板、失败提示
- 欢迎页（新会话空状态）
- 聊天区背景（网格纸 → 安静纸）
- 动效体系：transitions.dev motion tokens + 8 个关键时刻

**不在范围内**

- ChatInput composer 的结构与逻辑（仅做新令牌的配色适配，逻辑区零改动）
- 小地图、右侧面板、侧边栏、分支导航器
- 任何数据流/会话/滚动/分支逻辑

## 3. 设计令牌（方向 B）

### 3.1 色彩（聊天区，浅色 / 深色成对）

| 令牌              | 浅色                                  | 深色            | 用途                               |
| ----------------- | ------------------------------------- | --------------- | ---------------------------------- |
| `--chat-user-bg`  | `#eae3d5`                             | `#3a352c`       | 本地用户气泡（暖米色，替代近黑）   |
| `--chat-user-fg`  | `#3a352c`                             | `#f0ede6`       | 气泡文字（深字浅底，替代白字黑底） |
| `--chat-rule`     | `color-mix(border 70%, muted)`        | 同式            | 思考/过程组左侧细线                |
| `--chat-tool-row` | `rgba(text 4%)`                       | `rgba(#fff 4%)` | 工具轻行底色                       |
| diff 语义色       | 复用现有 `--success/danger` soft 体系 | —               | 不新增色板                         |

> 渠道消息（weixin/telegram/feishu）保留各自品牌色，仅本地气泡换为米色。通道色板文件同步更新。

### 3.2 字号 / 圆角 / 间距

- 字号：`--chat-f-micro: 11px`、`--chat-f-meta: 12px`、`--chat-f-body: 14px`、标题沿用 body 加权；全部乘以现有 `--chat-font-scale`
- 圆角：`--r-bubble: 14px`（尾角 4px）、`--r-block: 10px`、`--r-chip: 6px`
- 间距：消息间距 14px、块间距 10px、块内边距 12×14px

### 3.3 动效令牌（transitions.dev `_root.css`）

安装五维令牌（`--duration-stagger…very-slow`、`--ease-smooth-out…bounce-strong`、`--distance-*`、`--scale-*`、`--blur-*`）+ 手风琴/变形变量到全局样式。**触达代码中禁止出现 ad-hoc 时长/缓动。**

## 4. 改动清单（现状 → 改为 → 为什么）

### A. 结构预重构（动样式前的必要准备）

- [ ] **A1. 拆分 MessageView.tsx（1958 行 → 调度器 ≤150 行）**
  - 现状：用户/助手/思考/工具/diff/compaction/custom 全在一个文件，内联样式，无法局部维护。
  - 改为：`components/messages/` 下 `UserMessage` / `AssistantMessage` / `ThinkingBlock` / `ToolCallBlock` / `DiffViews` / `SystemMessages` / `shared.ts`，`MessageView.tsx` 只做角色分发。
  - 为什么：先让改动变容易。拆分本身零行为变化，typecheck+test 全绿为门槛。

### B. 视觉重构（方向 B）

- [ ] **B1. 聊天区背景**
  - 现状：28px 网格纸 + 四角橙色刻度线，欢迎页网格加重。
  - 改为：移除网格与刻度线，对话直接排在暖纸底色上。
  - 为什么：方向 B 的核心是「对话即文档」，装饰层与文字层争夺注意力。
- [ ] **B2. 用户气泡**
  - 现状：近黑色气泡、白字、`10px 10px 2px 10px` 硬切角。
  - 改为：暖米色气泡、深字、`14px/14px/4px/14px` 圆角尾角，行高 1.65。
  - 为什么：米色在暖纸上比黑块安静；圆角尾角保留方向感但不再生硬。
- [ ] **B3. 助手正文**
  - 现状：白卡 + 1px 边框 + 不对称圆角，每段正文都是盒子。
  - 改为：无卡片、无边框，正文直接排在纸上，行高 1.75；强调用暖橙下划线；行内代码浅芯片。
  - 为什么：连续阅读场景里，边框盒是视觉噪音；去盒后层级靠字重与留白表达。
- [ ] **B4. 流式状态行**
  - 现状：模型名 + 预估 token + 硬编码四色 t/s 徽章 + 7px 方块光标。
  - 改为：安静元信息行（模型 · token · t/s 用主题语义色分档），细圆点光标；**流式文字按 transitions.dev streaming-text 词级/字级模糊浮现落地**（用户已确认）：已定型部分走正常 Markdown 渲染，仅对「流式尾部」的 token 逐个加 `stream-in` 动画（按 token 序号作 key，旧 token 不重播）；中文按字、西文按词切分。
  - 为什么：速度徽章是页面里最扎眼的色块；降调后信息仍在，气质归位。词级浮现是流式体验的核心质感，预览中已验证观感。
- [ ] **B5. 思考块**
  - 现状：虚线边框盒、文本箭头 ▸/▾、瞬时展开、斜体正文。
  - 改为：左侧 2px 细线引文式（无框），标签「思考 · 12s」，手风琴展开（见 C1），思考中标签 shimmer。
  - 为什么：思考是辅助信息，应该比正文更轻，而不是多一个盒子。
- [ ] **B6. 工具调用块**
  - 现状：近黑终端块、橙色工具名、展开显示 JSON 与结果预览。
  - 改为：一行轻条（状态位 + 工具名 + 参数省略 + 耗时），点击手风琴展开入参/完整结果；diff 为内嵌白卡 + 行号；错误态用 danger 语义色。
  - 为什么：暗色块在纸面文档流里过重；轻条让「过程」退后、「结果」向前。
- [ ] **B7. 过程折叠组**
  - 现状：纯文字按钮「过程详情 · N 条消息」，瞬时展开。
  - 改为：同轻条语言 + 计数徽章 + 手风琴展开，子内容左侧细线与最终回答相连。
  - 为什么：与 B5/B6 统一折叠交互语言，三处种手势。
- [ ] **B8. compaction / extension / 失败提示**
  - 现状：三种面板各自为政（8px 圆角盒、边框、底部操作条）。
  - 改为：统一块令牌（10px 圆角、细边框、panel 底色），失败提示用 danger-soft 体系。
  - 为什么：低频组件沿用同一系统，不再各自发明。
- [ ] **B9. 欢迎页**
  - 现状：右上偏置 logo + "Dexon" 字标，网格加重。
  - 改为：居中安静构图，文字层（标识 + 问候）用交错浮现入场，网格移除。
  - 为什么：第一屏是方向 B 的门面；入场动效建立「安静但有生命」的第一印象。
- [ ] **B10. 悬停操作（复制/fork/编辑）**
  - 现状：hover 淡入用 ad-hoc `0.12s`，样式各异。
  - 改为：统一 `--duration-quick` + `--ease-out`，图标 12px 统一线宽。
  - 为什么：高频微交互是手感来源，令牌化后全页一致。
- [ ] **B11. composer 配色适配**
  - 现状：composer 用自身一套边框/底色变量。
  - 改为：仅把取色指向新令牌，结构与交互逻辑零改动。
  - 为什么：背景从网格纸变安静纸后，composer 需要跟随，但不承担重构风险。

### C. 动效时刻表（transitions.dev，全部带 prefers-reduced-motion 降级）

- [ ] **C1. 手风琴展开（21-accordion）**：思考块 / 工具块 / 过程组 / compaction。`grid-template-rows 0fr↔1fr` + 箭头 `scaleY` 翻转 + 内容模糊淡入。250ms `--ease-smooth-out`，开合对称（单一可逆手势，不拆分时长）。
- [ ] **C2. 工具状态位变形（41-spinner-check-morph，改造）**：运行中 spinner → 完成对勾（描边动画 + 弹性 pop）；错误变体为 danger 填充 + ×。去掉原方案 auto-revert（工具状态是持久事实，不该回弹）。
- [ ] **C3. 欢迎页文字交错浮现（18-texts-reveal）**：500ms + 40ms stagger + 12px 距离 + 3px 模糊。
- [ ] **C4. 思考中 shimmer（15-shimmer-text）**：思考块标签在流式期间微光扫过，结束后静止。
- [ ] **C5. 流式文字词级浮现（30-streaming-text，按用户要求完整落地）**：已定型部分正常 Markdown 渲染 + 流式尾部 token 逐个 `stream-in 420ms`（中文按字/西文按词），光标为圆点；每次新 token 仅挂载时动画一次，不重播历史 token。
- [ ] **C6. 悬停操作淡入淡出**：`--duration-quick` 150ms，开合对称。
- [ ] **C7. 通知条对齐主题令牌**：硬编码 `#ef4444 #d97706 #10b981` → `--danger/--warning/--success`（纯取色，无动画改动）。
- [ ] **C8. motion tokens 安装**：`_root.css` 五维令牌进全局样式，新增动效零 ad-hoc 值。

### D. 新增 i18n 词条

- [ ] **D1.** 思考时长标签（「思考了 {n} 秒 / Thought for {n}s」）、工具状态（进行中/已完成/失败）等新文案全部入字典，中英双语，`check:i18n` 通过。

## 5. 验收标准

| #   | 验收项        | 量化标准                                                                                                                 |
| --- | ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 1   | 预重构        | `MessageView.tsx` ≤150 行；`messages/` 新文件每个 ≤500 行；`typecheck`/`lint`/`test` 全绿                                |
| 2   | 方向 B 落地   | 网格+刻度线移除；助手正文无卡片；本地用户气泡米色；工具为轻条+内嵌 diff 卡（对照候选预览 B 板）                          |
| 3   | 令牌收敛      | 消息组件字号 ≤4 档、圆角 ≤4 档，全部经 CSS 变量引用，无裸值                                                              |
| 4   | 动效令牌      | 触达文件中 0 处 ad-hoc 时长/缓动（0.12s 等全部替换为 `var(--duration-*)`）                                               |
| 5   | 8 个动效时刻  | C1–C8 全部可演示，且每个在 `prefers-reduced-motion` 下退化为瞬时                                                         |
| 6   | 硬编码色清零  | t/s 徽章、通知条色点改主题变量；浅色/深色双主题人工核对无遗漏                                                            |
| 7   | i18n          | `npm run check:i18n` 通过；新增词条中英齐备                                                                              |
| 8   | 行为零回归    | 展开状态存储、滚动策略、分支、fork、队列、deferred 内容加载逻辑不动；手动冒烟：流式对话/思考/工具/错误/compaction/欢迎页 |
| 9   | composer 隔离 | `ChatInput.tsx` 逻辑区 diff 为零（仅样式取色变更）                                                                       |
| 10  | 文件规模      | 所有新建/改动文件 ≤500 行                                                                                                |
