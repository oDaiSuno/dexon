# 可恢复的工具交互卡片

普通问卷、选择、确认、文本输入、编辑和自定义面板都在聊天输入框上方展示。

## 使用规则

- 右上角收起按钮和卡片内 `Esc` 只收起，不取消请求。点击“继续回答”恢复。
- 单选的非末题选中后前进；末题停留，全部答案由用户手动发送。
- 可以跳题并发送已答内容；模型会明确收到未答题列表。全部不答使用“放弃本次回答”。
- 多选可以附带文字，也可仅写文字；单选的自定义文字与选项互斥。
- 放弃需要在卡片内再次确认，不会将草稿当作成功答案。
- 发送失败保留答案；成功、放弃、超时或停止后不会重新执行原请求。
- 同一会话的问题按到达顺序排队，其他会话的新问题不会抢焦点。
- 浏览器权限和敏感操作授权仍使用独立安全界面。

## 恢复范围

草稿保存在当前窗口的 `sessionStorage`，键为 `dexon-tool-draft:v1:<sessionId>`。恢复前必须核对后台实例与有效请求标识：

- 收起、会话／页面往返、刷新：后台仍有原请求时恢复当前题号、选择、文字和收起状态。
- 后台重启、停止或超时：旧请求不复活，显示失效状态。
- 不提供应用重启后的草稿归档，不向会话历史写入未提交答案。

后台使用递增版本的完整有效请求快照，拒绝旧版本回放。结束凭据最多保留 256 条；更旧的未知请求返回失效，不重新执行。

## 结构化问卷适配

完整逐题问卷目前适配已核对的 `@juicesharp/rpiv-ask-user-question` **2.7.1**。

通过 Pi 公开 `extensionsOverride` 替换该来源的桌面执行视图，不新增或强制启用工具，不修改用户安装包；原名称、参数、说明、结果含义和公开通知事件保留。未知来源／版本走原插件路径，仍可使用普通可恢复卡片，但不宣称具有完整问卷回改能力。

预览按完整原始文本展示，不解释或执行嵌入的 HTML／脚本。自定义面板保留终端内容与方向键等操作；`Tab` 移动浏览器焦点，专门按钮可向面板发送原始 Tab，避免焦点被困住。

## 回归验证

```sh
# 项目要求 Node 22
npm test
npm run test:interactive-tools-electron
npm run verify
```

交互窗口检查使用隔离测试会话、真实 Electron／React 卡片和 SDK 请求，不调用付费模型。生成 12 张双主题状态画面，检查 24 组宽度／字号组合、长编辑、减少动态效果和刷新恢复。另有真实 Agent 工具循环配合确定性模型替身，验证选项与原始文字确实进入下一次模型输入，重复响应不重复继续。

输出位于 `.artifacts/interactive-tools/electron/`。截图周围的聊天与输入框是测试容器，卡片本身是生产组件；不使用用户真实会话数据。
